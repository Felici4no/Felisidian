# Images

**Every image in this repository lives here.** This is the single place for
screenshots, GIFs, icons and diagrams. Do not add images next to code or docs.

| Folder | Use |
|---|---|
| `screenshots/` | Screenshots and GIFs used in the README and the marketplace listing |
| `icons/` | Logos and icons |
| `reference/` | Third-party visual references (kept local, git-ignored, never redistributed) |

## Conventions

- Reference images from docs with a relative path, e.g. `![Library](assets/images/screenshots/library.png)`.
- Use kebab-case names: `library-overview.png`, not `Screenshot 12.png`.
- Prefer `.png` for screenshots, `.svg` for icons, `.webp` for large photos.
- Keep each file under 1 MB.
